# Site statique Dr MAB

Site vitrine statique pour le Dr Musaab Abu Bakr, ophtalmologue à Saint-Raphaël.

## Hébergement

Le site ne nécessite aucun serveur applicatif. Il peut être hébergé sur Netlify, Vercel, GitHub Pages, OVH, o2switch ou tout hébergeur capable de servir des fichiers HTML/CSS/JS.

Fichiers principaux :

- `index.html`
- `le-docteur.html`
- `consultations.html`
- `pathologies.html`
- `informations-pratiques.html`
- `contact.html`
- `mentions-legales.html`
- `politique-confidentialite.html`
- `assets/styles.css`
- `assets/script.js`

## À compléter avant mise en ligne

- Remplacer les liens Doctolib `https://www.doctolib.fr/` par l'URL exacte du praticien.
- Ajouter l'adresse exacte du cabinet, le téléphone, l'email et les horaires.
- Remplacer les placeholders SVG dans `assets/images/` par les photos réelles du médecin et du cabinet, puis mettre à jour les chemins `src` dans les pages HTML si les extensions changent.
- Remplacer les blocs "Carte Google à intégrer" par l'iframe Google Maps officielle.
- Compléter la page `le-docteur.html` avec la formation et le parcours exacts.
- Compléter les mentions légales selon l'hébergeur, l'éditeur et les informations professionnelles exactes.

## SEO

Chaque page contient un titre et une meta description. La page `pathologies.html` sert de base SEO médicale locale, avec contenu informatif prudent et orienté patient.
